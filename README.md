# rbtree

This is an OCaml implementation of the paper [Deletion: The curse of the red-black tree](https://www.cambridge.org/core/journals/journal-of-functional-programming/article/deletion-the-curse-of-the-redblack-tree/471C92AF3D431403FEE6C66FE070C492)

## Developing this repo



```sh
git clone git@github.com:andrewbaine/rbtree.git
cd rbtree
opam install . --deps-only --with-test
```
